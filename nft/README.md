# AgentDraw — NFT artwork (style samples)

The 12 gallery artworks from agentdraw.click, rendered as standalone 800x800 PNGs
 straight from the same hand-coded 16x16 pixel maps the website draws with —
background pattern, palette and pixels are identical to the on-site rendering.

These are STYLE SAMPLES, not minted tokens. Every AgentDraw NFT is drawn live
by an AI agent at mint, so each token's final artwork is unique to that mint.
